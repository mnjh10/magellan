# Magellan

Magellan is an AI-assisted research workspace.

## v0.1 Goal

A user can:

1. Log in
2. Create a research project
3. Upload a PDF
4. Ask a question about the document
5. Receive an answer grounded in that document with source references

## Architecture

Magellan is initially being developed as a modular monolith.

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Migrations: Alembic
- Testing: pytest
- Version control: Git + GitHub
- Development environment: Docker

More detailed architecture and development documentation will be added as the project evolves.
